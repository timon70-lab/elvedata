# Lygna v1.067 — bilde- og videoikonene i kartet følger vannføringsfilteret

**Dato:** 2026-11-04
**Fil:** `lygna/index.html`
**Forrige versjon:** v1.066

## Hva ble endret

- `updateMap()`: bilde- og videomarkørene vises nå bare når sonen er valgt **og**
  `mediaPassesFilter()` slipper dem gjennom — samme kode som Audna, Mandalselva, Sygna og Tovdalselva.
  Med 💧-filteret av vises alle ikonene i valgt sone som før.
- Versjon v1.066 → v1.067.

Andre filer i samme commit: `docs/status-og-backlog.md` (versjonslinja).

## Hvorfor

Samme feil som Per Lasse fant i Otra: kartmarkørene var aldri koblet til vannføringsfilteret, selv om
`mediaPassesFilter()` fantes og ble brukt i bildevisningen. Rettet i samme runde som Otra v1.052.
