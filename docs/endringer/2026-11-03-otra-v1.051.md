# Otra v1.051 — ingen sort fokusramme rundt klikket sonepolygon

**Dato:** 2026-11-03
**Fil:** `otra/index.html`
**Forrige versjon:** v1.050

## Hva ble endret

- Ny CSS-regel `.leaflet-soneflater-pane path:focus { outline: none; }`.
- Versjon v1.050 → v1.051.

Andre filer i samme commit: `docs/status-og-backlog.md` (versjonslinja).

## Hvorfor

Per Lasse så en sort rektangulær ramme rundt sonen når han klikket på et sonepolygon. Leaflet gjør
polygonene klikkbare, så nettleseren gir det klikkede polygonet fokus og tegner fokusrammen rundt hele
polygonets utstrekning. Regelen gjelder bare sonelaget, så andre fokusmarkeringer på siden er uendret.

## Validering

- `python scripts/valider.py otra/index.html` — OK.
- Kart-UX A–C — uberørt.
- Manuelt i nettleserpanelet (PC): klikk på 4B Ravnås gir fokus på polygonet (`activeElement` = path)
  med `outline-style: none`, ingen ramme synlig, og soneinfo åpnes som før. Ikke testet på mobil.

## Oppfølging

- Samme regel må med når polygonene rulles ut til de øvrige elvene.
